Special Characters Typing Helper

Hold down keys to type accents and special characters

How to use:
  • Hold a key (e.g. e, a, o) for ~400ms.
  • If 1 variant exists (e.g. German s → ß), it replaces directly.
  • If multiple variants exist, a floating popup appears with numbered options.
  • Press 1-9, or use ← / → + Enter / Space, or click with mouse.
  • Press Escape or any other key to dismiss.
  • Hold Shift while holding a letter to get uppercase accents (e.g. È, É).

How to Include in Any HTML Page

Just drop a single script tag into your HTML page:

<!-- For Italian --> <script src="special-chars-it.js"></script>
